# Contributing

Bug reports and proposed changes should include:

1. MATLAB release and operating system.
2. A minimal, non-confidential input example.
3. The command used to run the workflow.
4. The complete error message or an explanation of the unexpected result.

Before submitting a code change, run `run_release_tests` from the repository root. Scientific changes that alter component selection, probability calculations, or inclusion decisions should include a focused regression test and an explanation of the intended interpretation.
